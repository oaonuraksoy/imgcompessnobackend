# Tarayıcı Tabanlı Görsel Sıkıştırma ve Optimize Edici (Client-Side)

🚀 **Tamamen tarayıcı üzerinde çalışan, sunucusuz (no-backend), hızlı ve güvenli görsel optimizasyon aracı.**

Bu araç, web siteleriniz veya projeleriniz için resimleri (JPEG, PNG) en iyi web formatı olan **WebP**'ye (veya diğer formatlara) dönüştürerek boyutlarını ciddi oranda küçültür. Tüm işlemler cihazınızın belleği üzerinde (Client-side Canvas API) gerçekleşir, bu sayede görselleriniz hiçbir uzak sunucuya yüklenmez; **%100 gizlilik ve veri güvenliği** sağlar.

## 🌟 Özellikler
- **Sunucusuz Mimari (No-Backend):** PHP, Node.js veya herhangi bir sunucu işlemi gerektirmez. Yalnızca HTML, CSS ve Vanilla JS ile çalışır.
- **Sürükle & Bırak ve Pano Desteği:** Görselleri ekrana sürükleyip bırakabilir veya direkt `Ctrl+V` / `Cmd+V` kısayoluyla panodan yapıştırabilirsiniz.
- **WebP Desteği:** Yeni nesil, SEO dostu WebP formatında çıktı alarak Google PageSpeed (Core Web Vitals) skorlarınızı artırın.
- **Anlık Analiz ve Karşılaştırma:** Orijinal dosya boyutu ile optimize edilmiş boyutu karşılaştırın, anında "% kaç tasarruf edildiğini" görün.
- **Esnek Kalite Ayarı:** Görsel kalitesini hassas kaydırıcı (slider) ile ayarlayarak en ideal boyut/kalite dengesini kendiniz belirleyin.

## 🛠 Kullanım
1. Uygulamayı tarayıcınızda açın (GitHub Pages linkine gidin veya yerel bilgisayarınızda `index.html` dosyasına çift tıklayın).
2. Optimize etmek istediğiniz görseli ekrana yapıştırın veya belirtilen alana sürükleyin.
3. Çıktı formatını ve kalite oranını (WebP için önerilen %80) seçin.
4. **"Web İçin Optimize Et"** butonuna tıklayın.
5. Sonuç ekranından küçültülmüş yeni görselinizi bilgisayarınıza anında indirin.

## 🚀 Kurulum & Yayına Alma (Deploy)
Proje tek bir `index.html` dosyasından oluştuğu için hiçbir karmaşık kuruluma, bağımlılığa veya veritabanına ihtiyaç duymaz. 
- Kendi web sitenizde yayınlamak için dosyayı sunucunuza (hosting) yüklemeniz yeterlidir.
- GitHub üzerinde ücretsiz yayınlamak için deponuzun **Settings > Pages** sekmesinden `main` branch'ini seçip **GitHub Pages**'i aktifleştirebilirsiniz.
